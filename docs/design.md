# 设计文档

目标：单轮（继承之前）的厚度向猫国建设者看齐，一轮玩 1 到 2 周。玩家每天上线几次，离线收益最多补 12 小时、全额。

厚度靠几套互相咬合的系统，而不是堆数量：

- **人手**：帮工是最核心的决策，有限的人分给谁。
- **季节**：冬天果树不结果，逼着玩家提前囤、提前准备。
- **农技**：研究解锁新东西，是阶段感的主要来源。
- **加工链**：木头做成木板，黏土烧成砖，果子熬成果酱。越往后链越长，原料互相抢。
- **面子和买家**：钱花在奢侈品上换面子，面子换出价更高的买家。

## 设计规则怎么落到分页上

CLAUDE.md 的 9 条规则不变，规则 9 改为按页理解：

- 页面分成：**农场、集市、帮工、农技、工坊、家**。没解锁的页不显示，页签只往后加。
- 每页是一列条目，**新条目只往最后加**，顺序按解锁先后记在存档里（`seen`），所以每个玩家看到的顺序都和自己的解锁顺序一致，已有的按钮永远不动。
- 研究完的科技留在原位，变成灰色的「已完成」，不消失（消失也会让下面的按钮移位）。
- 资源面板固定高度，资源多了在面板里滚动。故事栏固定 4 行。
- 果园图和买家名单不是按钮，放在页面最下面，可以变高。

## 帮工

- 不需要研究，买了锯子以后村里就有人来问，出现【工棚】（每间住 2 人）。
- 有空床位、仓库里有果子时，每 15 秒来一个人。每人每秒吃 0.5 个果子。果子吃光了，每 10 秒走一个人。
- 新来的人是闲着的，要在「帮工」页分配岗位：

| 岗位 | 出现 | 产出 |
|---|---|---|
| 果农 | 第一个帮工到 | 每人每秒 3 果子，受季节影响（冬天只剩 1/2） |
| 伐木工 | 第一个帮工到 | 每人每秒 1 木头 |
| 农技员 | 盖了书屋 | 每人每秒 0.25 农技 |
| 挖土工 | 研究「制砖」 | 每人每秒 0.5 黏土 |

## 季节和天气

- 第一个帮工来的时候出现日历（帮工会提醒「冬天果树不结果」）。在那之前没有季节。
- 每季 5 分钟，一年 20 分钟。
- 苹果树：春 ×1，夏 ×1.25，秋 ×1.5，冬 ×0。桃树夏天多，柑橘冬天多，温室四季一样。
- 每季开始时掷一次天气：一成丰年（果园 +25%），一成旱灾或寒潮（果园 −30%），其余正常。研究「灌溉」以后不怕旱。随机数种子存在存档里，离线补算和在线结果一样。

## 农技和科技树

帮工到 3 个时出现【书屋】（加农技上限），农技页随之出现；盖了书屋以后出现【看书】（手动 +1 农技）和科技。第一批科技：

| 科技 | 前置 | 效果 |
|---|---|---|
| 农时 | — | 果农 +25% |
| 嫁接 | — | 果树 +20%，出现桃树 |
| 木工 | — | 出现木板 |
| 制砖 | — | 出现黏土、挖土、土坑、挖土工、砖 |
| 砖瓦房 | 木工、制砖 | 出现砖房（每间住 5 人） |
| 农技站 | 木工、制砖 | 出现农技站（农技上限和产出都加） |
| 柑橘 | 嫁接 | 出现柑橘树（冬天产得最多） |
| 灌溉 | 嫁接 | 果树 +15%，不怕旱 |
| 整形修剪 | 嫁接 | 果树 +20% |
| 育林 | 木工 | 木头 +50% |
| 记账 | 农时 | 卖价 +10% |
| 堆肥 | 农时、制砖 | 果农 +25%，果树 +10% |
| 藏书 | 农技站 | 农技上限 +50% |
| 锯木坊 | 木工 | 出现锯木坊（自动做木板） |
| 砖窑 | 制砖 | 出现砖窑（自动烧砖） |
| 温室 | 柑橘、砖瓦房 | 出现温室（四季一样产） |
| 熬制 | 买了房、木头攒够 | 出现熬果酱（原来的阶段 6） |
| 冷链 | 熬制 | 出现冷库（加果酱上限） |
| 气象 | 农时、灌溉 | 坏天气的影响减半 |
| 推销 | 农时 | 出现推销员（自动按最好的价卖果子） |
| 机械化 | 锯木坊、砖窑 | 作坊、锯木坊、砖窑效率翻倍；采摘机器人和智慧果园要先研究它 |

原有的五金店、科技工具、生产工具、奢侈品、买家都保留，搬进「集市」和「家」页。生产工具改成每件 +25%，买家的价钱阶梯拉平（每 100 个果子 10 到 170 钱），配合奢侈品的真实价格，让第一年代撑满大约一天。

## 路线图（之后各轮）

| 年代 | 大约第几天 | 新系统 |
|---|---|---|
| 一 果园（本轮） | 第 1 天 | 上面这些 |
| 二 加工 | 第 2 到 3 天 | 果干（晒架，夏秋快）、果汁、果酒（酒窖）；产品各有买家偏好；帮工心情（食堂、电视），心情影响产量 |
| 三 市场 | 第 3 到 5 天 | 集市商人以物易物（化肥、种苗、设备）；销路：同一个买家卖多了降价；电商和网店 |
| 四 企业 | 第 5 到 8 天 | 合作社（租邻居的地）、品牌、农家乐（游客是新资源）、冷链物流 |
| 五 现代农业 | 第 8 到 14 天 | 智慧农业、航天育种、出口；一轮的终点是农业集团 |
| 继承 | 一轮结束后 | 下一代毕业后继承农场，带着部分东西重新开始 |

每个年代都要遵守：先手动再自动，限制和解法同时出现，没解锁的完全不显示。
